### `promo_prompts.js` (151줄) — B-2 5가지 튜닝 반영

| 함수·상수 | 시그니처 | 하는 일 |
|---|---|---|
| `KINDS` | 배열 11개 | 팟캐스트 뺀 11종 규칙(`id·key·label·target·max·rule`) |
| `PODCAST` / `PODCAST_PARTS` | 상수 | 7번 팟캐스트 + 3분할 정의 |
| `_fitMax` | `(target, cur) → number` | **개선안 부수** — `max(cur, ceil(target×1.6)+1200)` |
| `systemFor` | `(kind, ctx) → string` | 한 종류의 시스템 프롬프트 조립 |
| `systemForPodcastPart` | `(part, ctx, prevParts[]) → string` | **개선안 1** — 앞 Part 끝 200자를 넣어 중복 방지 |
| `fixInstruction` | `(kind, text) → string` | **개선안 5** — 보강/압축 지시문 |
| `inRange` | `(kind, text) → boolean` | 목표 ±20% 판정 |

**5가지 개선안이 코드 어디에 들어갔나**

| 개선안 | 반영 위치 |
|---|---|
| 1. 팟캐스트 분할 | `PODCAST_PARTS` + `systemForPodcastPart()` 의 `prevParts` 인자 |
| 2. 하위 항목 글자 상한 | `KINDS[].rule` — 예: 쇼츠 `[자막] 16자 이내 / [화면] 25자 이내` |
| 3. 불가능 목표치 현실화 | `KINDS[].target` — 쇼츠 240 · 이미지 1500 · 카드뉴스 380 · 스레드 320 |
| 4. 구조 + 항목별 상한 | `KINDS[].rule` 전체가 "정확히 N개" 형식 |
| 5. 자동 검사 + 1회 보강 | `inRange()` + `fixInstruction()` |

### `promo_skill.js` (216줄) — B-1 환각 차단 + 생성 엔진

| 함수·상수 | 시그니처 | 하는 일 |
|---|---|---|
| `init` | `({anthropic, model}) → void` | 주입식. main_server 를 require 하지 않는다 |
| `FACT_KEYS` | 상수 41개 | 키 → 없을 때 금지할 주제 |
| `parseFacts` | `(cell) → {filled, missing, filledCount, missingCount}` | 시트 한 칸을 `키: 값` 으로 파싱 |
| `factBlock` | `(facts) → string` | `<사실자료>` + `<모르는것>` 블록 생성 |
| `scanBanned` | `(text) → string\|null` | 금지 표현 검출(프롬프트가 뚫렸을 때 잡는 안전망) |
| `_call` | `(system, userText, maxTokens) → {text, truncated, inTok, outTok}` | **thinking 끔 + 빈 응답 예외** |
| `generateOne` | `(kind, ctx, copy) → 결과객체` | 한 종류 생성 + ±20% 밖이면 1회 보정 |
| `generatePodcast` | `(ctx, copy) → 결과객체` | 3분할 순차 생성 |
| `generateAll` | `(campaign, copy, copyNo) → {copy, results[], 요약}` | 12종 한 번에(11종 동시 + 팟캐스트 순차) |

**사실자료 주입 흐름**

```
시트 「캠페인」.내용_사실자료
   → parseFacts()   채워진 것 / 비어 있는 것으로 가른다
   → factBlock()    <사실자료> 블록 + <모르는것> 블록
   → systemFor()    프롬프트의 공통 규칙 바로 위에 삽입
   → 원고 생성
   → scanBanned()   그래도 금지 표현이 나왔는지 확인
```

**빈 항목 강제 규칙 (실제 프롬프트 문구)**

```
- 구체적인 정의·풀이·항목 이름을 쓰지 않는다
- 개수를 말하지 않는다 ("5가지", "8단계" 같은 표현 금지)
- 숫자·수치·연차·금액·비율·통계를 쓰지 않는다
- 약자를 글자별로 풀지 않는다
★대신 이름만 쓰고 일반적인 톤으로 넘어간다. 원고는 정상적으로 완성한다.
```
