```
// ═══ 📣 홍보마케팅비서 2단계 — 카피 1건 → 원고 12종 (독립 모듈 · CLAUDE.md 6-2 ⑦) ═══
//   위의 /api/promo/draft·expand 는 교육생이 쓰는 중이라 한 글자도 안 건드린다.
//   새 기능은 /api/promo2/* 로 따로 낸다. 이 파일이 바뀌는 건 아래 3줄뿐이다.
const promoSkill = require('./promo_skill');
promoSkill.init({ anthropic: _anthropic, model: WS_CHAT_MODEL, sessionOf });
app.use('/api/promo2', promoSkill.router);
```

**주입 변수가 이 줄보다 앞에 정의돼 있는지 확인함** (undefined 로 들어가면 조용히 망가집니다)

|---|---|---|
| `_anthropic` | 37줄 | ✅ 앞 |
| `WS_CHAT_MODEL` | 44줄 | ✅ 앞 |

**기존 `/api/promo/draft`·`/api/promo/expand` 는 한 글자도 안 건드렸습니다.**

## 라우트 6개 — 실제 등록 확인

`node` 로 모듈을 올려 라우터 스택을 읽어봤습니다.

```
GET  /api/promo2/campaigns
GET  /api/promo2/copies
POST /api/promo2/copies
POST /api/promo2/expand12     ← 2단계 핵심
GET  /api/promo2/scripts
GET  /api/promo2/diag
종류수: 12
```

| 경로 | 하는 일 |
|---|---|
| `GET /campaigns` | 「캠페인」 탭 읽기. **사실자료 원문은 안 내려보냄** — 채움/미기재 개수만 |
| `GET /copies?key=` | 「한줄카피」 탭 읽기 |
| `POST /copies` | txt 업로드 → 최대 60개 저장(초과분은 몇 개 버렸는지 알림) |
| `POST /expand12` | **카피 1건 → 원고 12종 → 시트 기록** |
| `GET /scripts?key=&no=` | 만들어진 원고 조회 |
| `GET /diag` | 진단 창구 — **실제와 같은 함수를 탄다**(CLAUDE.md 6-7) |

**전부 로그인 게이트 뒤에 있습니다.** `sessionOf` 를 주입받아 401을 냅니다.

## 시트 스키마 (코드 실물)

| 탭 | 머리글 |
|---|---|
| **캠페인** | 캠페인키 · 서비스 · 내용 · 코드 · 진단URL · 랜딩URL · 톤앤매너 · **내용_사실자료** · 상태 · 생성일시 |
| **한줄카피** | 캠페인키 · 번호 · 카피 · 상태 · 등록일시 |
| **원고** | 캠페인키 · 카피번호 · 원고종류 · 라벨 · 본문 · 글자수 · 달성률 · 보정 · **금지표현** · 모델 · 생성일시 |

**탭이 없으면 자동으로 만들고 머리글을 넣습니다**(`ensureTab`). 회장님이 빈 시트만 만들어 주시면 됩니다.

**「원고」 탭에 `금지표현` 칸을 넣은 이유:** 환각이 뚫렸을 때 어느 원고에서 났는지 시트에서 바로 보이게 하려고입니다.
