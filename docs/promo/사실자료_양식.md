# 지니야 홍보마케팅비서 · 사실자료 (환각 방지용)

회장님, 아래 빈칸만 채워 주시면 지니야가 지어내지 않습니다.
모르거나 아직 없는 칸은 **"없음"** 이라고 적어 주세요.

> **비워두셔도 원고는 정상적으로 만들어집니다.**
> 다만 그 부분은 구체적으로 설명하지 않고 **일반적인 톤으로만** 씁니다.
> → **모르면 안 쓰지, 지어내지 않습니다.**

한 번에 다 채우지 않으셔도 됩니다. **1·2·9·10번이 가장 급합니다** — 원고에 가장 자주 등장합니다.

---

## 1. DESIRE — 무엇의 약자입니까

왜 필요: 지니야가 "다섯 글자"라고 잘못 말하고 항목을 창작했습니다(실제 6글자).

```
DESIRE = ________________________________________________
```
(예시) "재무 목표 달성을 위한 6단계 진단 도구"

## 2. D·E·S·I·R·E 각 글자의 정확한 뜻

왜 필요: 원고마다 6개가 등장합니다. 하나라도 비면 지어냅니다.

```
D = __________ · 한 줄 설명 ____________________________
E = __________ · 한 줄 설명 ____________________________
S = __________ · 한 줄 설명 ____________________________
I = __________ · 한 줄 설명 ____________________________
R = __________ · 한 줄 설명 ____________________________
E = __________ · 한 줄 설명 ____________________________
```
(예시) D = Debt(부채) · 새는 돈부터 막는 단계

## 3. 금융집짓기 8단계

왜 필요: "8단계"라는 숫자만 알면 내용 8개를 창작합니다.

```
1단계 ____________   2단계 ____________
3단계 ____________   4단계 ____________
5단계 ____________   6단계 ____________
7단계 ____________   8단계 ____________
```
(예시) 1단계 = 터 다지기(비상자금 3~6개월)

## 4. 금융오행 5요소

왜 필요: "오행"이라는 이름만 알면 5개를 임의로 만듭니다.

```
① ________ ② ________ ③ ________ ④ ________ ⑤ ________

각 요소 한 줄 설명: ____________________________________
```

## 5. 진단 항목 정의

왜 필요: "수입지출 진단"이 정확히 뭘 보는지 몰라 임의로 설명합니다.

```
수입지출 진단 → 무엇을 봅니까? _______________________
자산부채 진단 → 무엇을 봅니까? _______________________
연금 진단     → 무엇을 봅니까? _______________________
그 외 진단    → ______________________________________
```

## 6. 서비스별 CTA 정확 문구

왜 필요: 지금은 지니야가 CTA 문장을 매번 다르게 만듭니다. 브랜드 문구는 고정이어야 합니다.

```
재무상담     → "___________________________________"
부트캠프     → "___________________________________"
일반인 강의  → "___________________________________"
전문가 강의  → "___________________________________"
```
(예시) 부트캠프 = "1분 무료 진단으로 내 위치부터 확인하세요"

## 7. 오상열 대표님 소개 — 쓸 수 있는 사실만

왜 필요: 경력·수치를 지어내면 신뢰 사고로 직결됩니다.

```
경력 / 자격: __________________________________________

쓸 수 있는 숫자: ______________________________________
   (예: 유튜브 구독자 4.7만 · 팟캐스트 365회 · CFP 25년)

★절대 쓰면 안 되는 표현: ______________________________
```

## 8. 자주 나오는 기타 사실

```
회사 정식 명칭: _______________________________________
부트캠프 정식 명칭: ___________________________________

가격을 원고에 써도 됩니까?   □ 예    □ 아니오
   → "예" 라면 정확한 금액: ___________________________

기타 꼭 지켜야 할 표현: _______________________________
```

## 9. DESIRE 5분 무료 진단 · 정확 정의 ★리드마겟 훅

왜 필요: 홍보 마스터플랜의 리드마겟 훅입니다. 지금은 지니야가 진단 내용을 임의로 설명합니다.

```
5분 진단은 무엇을 진단합니까?  ________________________
어떤 질문 몇 개로 구성됩니까?  ________________________
결과 화면에 무엇이 나옵니까?   ________________________
결과 이후 다음 단계 CTA는?     ________________________
```
(예시) "당신의 자산건강 5분 진단 · 12개 질문 · 집짓기 색띠 결과 · 무료 상담 예약 CTA"

## 10. 오원트·지니야 정확 정의 · 사업 브랜드 ★가장 자주 등장

왜 필요: 홍보 원고 전반에 "1인 사업자를 위한 AI 비서" 방향이 반복 등장합니다.
지어내면 회장님 사업 브랜드가 왜곡됩니다.

```
오원트금융연구소 핵심 미션 · 한 줄:
  ____________________________________________________

지니야 정확한 정의 · 한 줄:
  ____________________________________________________

지니야 대상 고객 · 정확 표현:
  ____________________________________________________

지니야 vs 다른 AI 비서 차별점 · 한 줄:
  ____________________________________________________
```
(예시)
- "오원트 = 1인 사업자·CFP·설계사를 위한 AI 파트너"
- "지니야 = 명단·이벤트·발송을 스스로 챙기는 자율 AI 비서"

---

## 지니야가 이 자료를 쓰는 방식

| 사실자료 상태 | 지니야 동작 |
|---|---|
| **채워져 있음** | 그 문장을 **그대로** 사용. 변형·확장하지 않음 |
| **비어 있음** | 원고는 **정상 생성**. 단 그 주제의 **구체적 정의·항목 수·수치·약자 풀이를 쓰지 않고** 일반 톤으로만 씀 |

**예시 — DESIRE 항목이 비어 있을 때**

- ❌ 지금(환각): "DESIRE는 다섯 글자, D=방향성 E=실행력 S=안정성 I=정보력 R=회복력…"
- ✅ 바뀐 뒤: "DESIRE 진단으로 지금 내 위치를 확인할 수 있습니다. 1분이면 됩니다."

나중에 채우셔도 됩니다. 채우는 즉시 다음 원고부터 반영됩니다.
