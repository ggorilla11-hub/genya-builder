## Day 2 · 시트 통합 + 배치(60개 일괄)

### 파일

| 구분 | 경로 |
|---|---|
| 신규 | `deploy/promo_batch.js` — Anthropic Batch API 제출·폴링·수거 |
| 수정 | `deploy/genya.html` — 버튼 1개 |

### 라우트

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| POST | `/api/promo2/batch/start` | 카피 60개 × 12종 = **720건** 제출 → batchId |
| GET | `/api/promo2/batch/status?id=` | 진행률(성공/실패/대기) |
| POST | `/api/promo2/batch/collect?id=` | 결과 수거 → 「원고」 탭 일괄 기록 |

### 왜 배치인가

| | 실시간 | 배치 |
|---|---|---|
| 용도 | 1건 미리보기 | 60개 일괄 |
| 비용 | 278원/카피 | **약 50%** |
| 시간 | 72초 | 최대 1시간 |
| 레이트리밋 | 720건 동시 → 위험 | 안전 |

### UI 컴포넌트

- **[60개 일괄 만들기] 버튼**
- 진행률 표시 (폴링) — "완료 N/60"
- 실패 건 목록 + 재시도 버튼

### 실측 시나리오

```
1. 카피 3개(36건)로 소량 먼저 실측
2. 이상 없으면 60개(720건) 실행
3. 「원고」 탭 720행 확인
```

### 팀장 검수 관문

- [ ] 36건 소량 실측 통과 후에만 720건 진행
- [ ] 시트 720행 기록 확인
- [ ] 비용이 실시간 대비 약 50%인지 확인
- [ ] 실패 건 재시도 동작
